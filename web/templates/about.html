Project Overview

This project develops an AI-based manufacturing defect detection system using transfer learning with EfficientNet-B0 and ResNet-50, combined with Grad-CAM for explainable AI. The system classifies transistor images as "Good" or "Defective" and provides visual heatmaps highlighting the exact regions that triggered the defect detection.

Manual quality inspection in manufacturing is slow, inconsistent, and difficult to explain. This system addresses these challenges by providing accurate, automated defect detection with visual explanations that build operator trust.

Model Architectures

EfficientNet-B0

  • Backbone: EfficientNet-B0 pretrained on ImageNet (1.2M images, 1000 classes)
  • Classifier: Dropout(0.3) → Linear(1280, 256) → ReLU → Dropout(0.2) → Linear(256, 2)
  • Parameters: ~5.3M total, custom head trainable first
  • Advantage: Compact, fast inference, great for deployment

ConvNeXt-Tiny (Default)

  • Backbone: ConvNeXt-Tiny pretrained on ImageNet
  • Classifier: LayerNorm → Flatten → Linear(768, 2)
  • Parameters: ~28.0M total
  • Advantage: Modern architecture, best balance of speed, accuracy, and robust out-of-domain detection

ResNet-50

  • Backbone: ResNet-50 V2 pretrained on ImageNet
  • Classifier: Dropout(0.3) → Linear(2048, 256) → ReLU → Dropout(0.2) → Linear(256, 2)
  • Parameters: ~25.6M total
  • Advantage: Well-studied, robust feature extraction

Training Strategy

  • Transfer Learning: Freeze backbone → train classifier (3 epochs) → unfreeze all → fine-tune
  • Optimizer: AdamW with weight decay (1e-4)
  • Scheduler: OneCycleLR (cosine annealing)
  • Loss: Weighted CrossEntropy (handles class imbalance)
  • Mixed Precision: FP16 with GradScaler for 2x speedup

Grad-CAM Explainability

Gradient-weighted Class Activation Mapping (Grad-CAM) is an explainable AI technique that produces visual explanations for CNN decisions. It uses the gradients flowing into the final convolutional layer to produce a coarse localization map highlighting important regions.

1

Forward pass: compute class score for the predicted class

2

Backward pass: compute gradients w.r.t. the last conv layer's feature maps

3

Global average pool the gradients to get neuron importance weights

4

Weighted combination of feature maps → ReLU → heatmap overlay

Grad-CAM targets: EfficientNet-B0: features[-1] | ConvNeXt-Tiny: features.7.2.block | ResNet-50: layer4[-1]
